# Services

The app lists services that answer with a live x402 price. The site checks each one every few minutes with an unpaid request (asking the price is free) and only shows the ones that respond, with the price they quote right now.

Services currently listed include:

| Service | What you get | Typical price |
| --- | --- | --- |
| Exa | Web search built for AI | under a cent per search |
| Exa Contents | Any web page as clean text | about a tenth of a cent per page |
| CoinGecko | Live price of any coin | $0.01 per lookup |
| CoinGecko Pools | Trading pools for a token on Solana | $0.01 per search |
| Nansen | Smart-money flows | a few cents per query |
| Bitrefill | Gift cards (see [Gift cards](gift-cards.md)) | card value plus a small fee |
| PayAI Echo | A test purchase that is refunded | refunded |

Prices are set by each service and can change. The approval screen always shows the exact amount before you pay.

## Any other paid link

Fomo Spend isn't limited to this list. Paste any URL that answers with an x402 price into **Pay**, add its site to your allowed list, and pay it the same way.

Names and logos belong to their owners. Fomo Spend is not affiliated with or endorsed by these services; it pays their public pay-per-use links.
